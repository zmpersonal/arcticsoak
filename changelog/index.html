Changelog

What changed and why.

Model 2.0.0 — September 17, 2026

  • Replaced the single optimistic point estimate with efficient, reference and high-load scenarios.
  • Raised and disclosed baseline energy assumptions for circulation, filtration and sanitation.
  • Added explicit daily allowances for unmodeled exposure and use loads.
  • Changed climate load from monthly-mean-only logic to positive degree-hours derived from monthly low/high profiles.
  • Added ambient-temperature COP degradation.
  • Added 55°F, 50°F, 45°F and 39°F target-temperature sensitivities.
  • Added source status, station fields, electricity period, model version and generated timestamp to downloads.
  • Added JSON, per-city records, permanent release snapshots and CC BY 4.0 licensing.
  • Stopped claiming provisional seed rows are NOAA observations.

Model 1.0.0 — September 2026

Initial 100-gallon, 50°F comparison model using one baseline load, one conductance constant, fixed COP, monthly mean temperatures and state electricity rates. Retained here so older citations can be interpreted; superseded because it understated uncertainty and omitted important loads.
